`iq-tooltip` directive. Arguments: Params | Type | Details| :--- | :--- | :--- iq-tooltip | Boolean | optional value - if the iq-tooltip attr itself has a value, this value is taken to mean whether the tooltip is enabled. Thus if false, it is as if the directive isn't applied at all tooltip-text | String | tooltip-class | String | optional - one or multiple classes to use for the tooltip tooltip-attach-to-body | void | optional - if truthy the tooltip will be attached to body. Defaults to false tooltip-delay | String | optional - time in millis between hover and tooltip showing. Defaults to 300 tooltip-only-on-overflow | Boolean | optional - tooltip will only show when the element overflows horizontally. Defaults to false tooltip-overflow-element-selector | String | optional - used for detecting overflow in child element tooltip-content-is-html | Boolean | optional - if set to true then the tooltip-text value may contain HTML which will be rendered. Defaults to false
