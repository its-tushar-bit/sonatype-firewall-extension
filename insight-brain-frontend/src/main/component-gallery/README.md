## What is Component Gallery
Component Gallery is a web application for cataloguing, documenting and showcasing IQ reusable components and styles.

It picks up changes to IQ source automatically so it can be used for development and testing of IQ reusable components and styles. 
Simply change IQ source code and refresh the Component Gallery in the browser.
 
## Setup
- Make sure your node version is at least `v6.5.0`. To display your node version use `node -v` command.
- Run `npm install` in case you didn't run `mvn install`.

## Run gallery app
```
npm run start-gallery
```

Open the app in your browser: http://localhost:4040
