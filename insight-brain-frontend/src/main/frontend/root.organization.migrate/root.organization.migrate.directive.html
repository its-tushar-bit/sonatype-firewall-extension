The Root Organization for setting global policy is now available. Creating the Root Organization is a one time process, and occurs when IQ Server is restarted.

  • It is strongly recommended that you choose an existing organization to act as a template for the configuration of the Root Organization.
  • You may create an empty Root Organization. This choice is discouraged because once the Root Organization is created, moving policy from existing organizations or applications becomes a manual task.
  • Backup the IQ Server and read the upgrade instructions before proceeding.
The Root Organization is now configured. You must restart the IQ Server to create the Root Organization.
