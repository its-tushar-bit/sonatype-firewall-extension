Sonatype Firewall — UI mockups

Seven static HTML mockups covering both sides of the Sonatype Firewall browser-extension integration: three new/updated pages in the IQ Server frontend (insight-brain), and four surfaces of the Chrome extension (Verdict, History, Scan detail, Settings). Open in a browser to review layout, spacing, and interaction states. Copy tweaks live in docs/IMPLEMENTATION.md.

IQ Server — new pages

  • 1. Browser Extension page (new)
    Firewall → Browser Extension. Lists scans submitted by the extension against a Virtual Repository Manager. New sidebar entry, new route.
  • 2. Waiver Requests — Source + Scope columns, grouped cascade waivers
    Existing Waiver Requests page with new Source column, new Scope column, and a source filter. Cascade waivers (one request → multiple scope rows) render as a grouped parent + expanded children sharing a waiver_group_id.
  • 3. Waiver Requests — Extension requests tab
    Same page as (2), third top-tab active. Client-side filter shows only extension-originated waiver requests, with the grouped cascade view.

Chrome extension popup

  • 4. Verdict tab — default, scope picker, submit result
    The primary popup surface: current package’s verdict, policy reasons, CVEs, golden version. Request waiver expands into a scope picker driven by GET /policyWaiverRequests/scope-options. Submit result confirms cascade rows created under one waiver_group_id.
  • 5. History tab — recent scans + empty state
    Session-scoped list of up to 20 recently-scanned packages, newest first, persisted to chrome.storage.local. Current-view row is highlighted. Clicking a row swaps the Verdict tab to that entry. Empty state covers first-use.
  • 6. Scan detail tab — happy + degraded paths
    Per-call diagnostic breakdown: each API call the extension made (details, evaluate, remediation, scope-options), with method, path, status, latency. Expanded row shows raw JSON. Degraded state shows how a 401 on evaluate makes the Verdict tab display partial data.
  • 7. Settings page — IQ Server configuration
    The Options page (opens as a full Chrome tab from the popup’s Settings link). Three variants: Real mode connected with successful Test-connection showing resolved VRM child repos, Test failed (401) error state with fix hint, and Mock mode where real-IQ sections are hidden.
