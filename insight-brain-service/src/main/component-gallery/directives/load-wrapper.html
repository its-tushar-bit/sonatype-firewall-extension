`load-wrapper` directive wraps the content being loaded and displays loading indicator while `loading="true"`. If content is loaded with no errors, the wrapped content is shown. In case of error, error object should be passed to `load-wrapper` attribute. If error object is truthy, error message with retry button is shown. Custom error message can be provided with `message` attribute. Arguments: Params | Type | Details| :--- | :--- | :--- loading | expression | if truthy loading indicator is shown load-wrapper| expression | error Object or String message | expression | String to use instead of default error message. See load-error directive. reload | expression | will be executed when "Retry" button is clicked
