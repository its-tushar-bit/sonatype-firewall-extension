`<iq-tree-view-radio-select>` is a Radio select widget using tree-view. __Note:__ in contrast to `iq-tree-view-multi-select`, this component doesn't support filtering of options with fuzzy filter. This components provides one-directional bindings only. Updates to selected option state are notified via `on-change` callback. __Note:__ this component is designed to support unidirectional data flow: it doesn't maintain the state of selected option and expects to receive updated 'selectedId' state from the parent. Arguments: Params| Type | Details| :--- | :--- | :--- available | [{id:Any, name:String}] | Array of available options selected-id | Any | id of selected option on-change | callback expression | called with the id of currently selected option. Context: {selected:Any} read-only | Boolean | optional - if true, renders collapsed and disabled tree view (defaults to 'false') In the example below, triggered on-change callback is logged to console.
