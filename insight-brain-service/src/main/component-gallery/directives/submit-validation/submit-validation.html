`submit-validation` directive. Visually enables/disables a form submit button based on the validity of the form. NOTE: Does not actually disable the submit button - the form submit handler or button click handler must also check the form validity before saving. Arguments: Params | Type | Details :--- | :--- | :--- submit-dirty | expression | expression computing to a boolean indicating whether the form is dirty submit-type | expression | optional - expression computing to a string which should be a verb describing the submission action. Defaults to 'save'. If it is 'update', submission will be blocked when submit-dirty is false submit-tooltip-target | string | optional - CSS selector of element to bind tooltip to. Useful for elements that are relatively positioned
